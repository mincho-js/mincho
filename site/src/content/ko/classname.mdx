# 클래스 이름 유틸리티

Mincho는 CSS 클래스 이름을 일관되고 타입 안전하게 만들고 관리할 수 있는 유틸리티 함수를 제공합니다.

## 설치 [#installation]

```bash
npm install @mincho-js/css
```

## 개요 [#overview]

클래스 이름 유틸리티로 다음 작업을 할 수 있습니다.

- `cx()`로 **조건에 따라 클래스 이름 결합하기**
- `cx.with()`로 **타입으로 클래스 이름 제약 정의하기**
- `cx.multiple()`로 **여러 클래스 이름 유틸리티 생성하기**

## cx() [#cx]

`cx()` 함수는 조건에 따라 클래스 이름을 하나의 문자열로 결합합니다. [clsx](https://github.com/lukeed/clsx)에서 영감을 받았으며 같은 방식으로 편리하게 사용할 수 있습니다.

```typescript
import { cx } from '@mincho-js/css';

// Strings (variadic)
cx('foo', true && 'bar', 'baz');
// => 'foo bar baz'

// Objects
cx({ foo: true, bar: false, baz: isTrue() });
// => 'foo baz'

// Arrays
cx(['foo', 0, false, 'bar']);
// => 'foo bar'

// Kitchen sink (with nesting)
cx('foo', [1 && 'bar', { baz: false, bat: null }, ['hello', ['world']]], 'cya');
// => 'foo bar hello world cya'
```

### 문자열 입력 [#string-inputs]

문자열을 인수로 직접 전달합니다.

```typescript
cx('foo', 'bar', 'baz');
// => 'foo bar baz'
```

### 조건부 문자열 [#conditional-strings]

불리언 표현식으로 조건부 클래스 이름을 지정합니다.

```typescript
const isActive = true;
const isHidden = false;

cx('base', isActive && 'active', isHidden && 'hidden');
// => 'base active'
```

### 객체 입력 [#object-inputs]

키는 클래스 이름, 값은 조건인 객체를 사용합니다.

```typescript
cx({
  'btn': true,
  'btn-primary': isPrimary,
  'btn-disabled': isDisabled,
});
// => 'btn btn-primary' (when isPrimary is true, isDisabled is false)
```

### 배열 입력 [#array-inputs]

배열은 재귀적으로 펼쳐서 처리합니다.

```typescript
cx(['foo', 'bar']);
// => 'foo bar'

// Nested arrays
cx(['foo', ['bar', ['baz']]]);
// => 'foo bar baz'
```

### 입력 형식 혼합 [#mixed-inputs]

모든 입력 형식을 함께 사용할 수 있습니다.

```typescript
cx(
  'base',
  isActive && 'active',
  { 'highlighted': isHighlighted },
  ['extra', 'classes']
);
```

## cx.multiple() [#cxmultiple]

값의 맵에서 여러 클래스 이름 문자열을 만듭니다.

```typescript
import { cx } from '@mincho-js/css';

const textStyles = cx.multiple({
  primary: ['text-blue-500', 'font-bold'],
  secondary: ['text-gray-500', 'font-normal'],
  danger: ['text-red-500', 'font-semibold']
});

// Usage
textStyles.primary;
// => 'text-blue-500 font-bold'

textStyles.secondary;
// => 'text-gray-500 font-normal'
```

### 조건부 로직 사용 [#with-conditional-logic]

맵 안에서도 같은 조건부 패턴을 사용할 수 있습니다.

```typescript
const isActive = true;
const hasError = false;

const buttonStates = cx.multiple({
  primary: {
    'bg-blue-500': true,
    'text-white': true,
    'opacity-50': !isActive
  },
  secondary: [
    'bg-gray-500',
    isActive && 'hover:bg-gray-600',
    hasError && 'border-red-500'
  ],
  danger: [
    'bg-red-500',
    { 'font-bold': isActive, 'italic': hasError },
    !hasError && 'shadow-md'
  ]
});

buttonStates.primary;
// => 'bg-blue-500 text-white'

buttonStates.secondary;
// => 'bg-gray-500 hover:bg-gray-600'
```

## cx.with() [#cxwith]

타입이 지정된 클래스 이름 유틸리티를 만듭니다. 콜백 없이 사용하면 `cx.with<T>()`는 일반적인 가변 인수 `cx()` 호출 형식을 유지하면서 허용되는 클래스 값을 제한합니다.

```typescript
import { cx } from '@mincho-js/css';

// Define allowed class names
type LayoutDisplay = 'flex' | 'grid' | 'block';
type LayoutSpacing = `p-${number}` | `m-${number}`;

const layout = cx.with<LayoutDisplay | LayoutSpacing>();

layout('flex', 'p-4');
// => 'flex p-4'

// TypeScript error: Type '"inline"' is not assignable
// layout('inline'); // Error!
```

### 위치 인수 믹스인 패턴 [#positional-mixin-pattern]

`cx.with()`를 클래스 이름 믹스인처럼 사용하려면 콜백을 전달합니다. 반환된 함수는 콜백의 매개변수를 그대로 받고, 콜백의 결과를 `cx()`로 변환합니다.

```typescript
const responsive = cx.with((base: string, md?: string, lg?: string) => [
  base,
  md && `md:${md}`,
  lg && `lg:${lg}`
]);

responsive('text-sm', 'text-base', 'text-lg');
// => 'text-sm md:text-base lg:text-lg'

responsive('text-sm');
// => 'text-sm'
```

매핑 함수처럼 동작해야 한다면 나머지 매개변수를 받는 믹스인으로 표현합니다.

```typescript
const prefixed = cx.with((...classNames: string[]) =>
  classNames.map((className) => `ui-${className}`)
);

prefixed('button', 'active');
// => 'ui-button ui-active'
```

### cx.with().multiple() [#cxwithmultiple]

콜백 매개변수에 맞는 튜플 값을 전달해 콜백 기반 `cx.with()`와 `multiple()`을 함께 사용합니다.

```typescript
const responsive = cx.with((base: string, md?: string, lg?: string) => [
  base,
  md && `md:${md}`,
  lg && `lg:${lg}`
]);

const result = responsive.multiple({
  heading: ['text-xl', 'text-2xl', 'text-3xl'],
  body: ['text-sm', 'text-base'],
  caption: ['text-xs']
} as const);

result.heading;
// => 'text-xl md:text-2xl lg:text-3xl'

result.body;
// => 'text-sm md:text-base'

result.caption;
// => 'text-xs'
```

객체 인수 하나를 받는 믹스인에서 `multiple()`을 사용할 때는 객체를 튜플로 감쌉니다.

```typescript
const responsiveObject = cx.with<{ base: string; md?: string }>(
  ({ base, md }) => [base, md && `md:${md}`]
);

const objectResult = responsiveObject.multiple({
  body: [{ base: 'text-sm', md: 'text-base' }],
  caption: [{ base: 'text-xs' }]
} as const);
```

## cva() (예정) [#cva-coming-soon]

변형 기반 클래스 관리를 위한 `cva()` 함수는 향후 구현할 예정입니다.

```typescript
// Future API (not yet available)
import { cva } from '@mincho-js/css';

const button = cva({
  base: 'rounded border font-semibold',
  variants: {
    intent: {
      primary: 'border-transparent bg-blue-500 text-white',
      secondary: 'border-gray-400 bg-white text-gray-800',
    },
    size: {
      small: 'px-2 py-1 text-sm',
      medium: 'px-4 py-2 text-base',
    },
  },
  compoundVariants: ({ intent, size }) => [
    {
      condition: [intent.primary, size.medium],
      class: 'uppercase',
    },
  ],
  defaultVariants: {
    intent: 'primary',
    size: 'medium',
  },
});

button();
// => 'font-semibold border rounded bg-blue-500 text-white...'

button({ intent: 'secondary', size: 'small' });
// => 'font-semibold border rounded bg-white text-gray-800...'
```

### cva.raw() (예정) [#cvaraw-coming-soon]

조합에 사용할 수 있도록 cva 설정 객체를 그대로 반환합니다.

```typescript
// Future API
const buttonConfig = cva.raw({
  base: 'rounded border font-semibold',
  variants: {
    intent: {
      primary: 'bg-blue-500 text-white',
      secondary: 'bg-gray-500 text-white'
    }
  }
});
// buttonConfig is a plain object, not a function
```

### cva.multiple() (예정) [#cvamultiple-coming-soon]

맵에서 여러 변형 유틸리티를 만듭니다.

```typescript
// Future API
const buttons = cva.multiple({
  primary: {
    base: 'rounded border',
    variants: {
      size: {
        small: 'px-2 py-1 text-sm',
        large: 'px-4 py-2 text-lg'
      }
    }
  },
  secondary: {
    base: 'rounded border-2',
    variants: {
      size: {
        small: 'px-2 py-1 text-sm',
        large: 'px-4 py-2 text-lg'
      }
    }
  }
});

buttons.primary({ size: 'small' });
buttons.secondary({ size: 'large' });
```

### cva.with() (예정) [#cvawith-coming-soon]

매개변수를 받는 변형 유틸리티를 만듭니다.

```typescript
// Future API
const myButton = cva.with<{ bg: string; text: string }>(
  ({ bg, text }) => ({
    base: 'rounded border',
    variants: {
      size: {
        small: 'px-2 py-1 text-sm',
        large: 'px-4 py-2 text-lg'
      }
    },
    compoundVariants: ({ size }) => [
      {
        condition: [size.small],
        class: `bg-${bg} text-${text}`
      }
    ]
  })
);

const button = myButton({ bg: 'blue-500', text: 'white' });
button({ size: 'small' });
// => 'rounded border px-2 py-1 text-sm bg-blue-500 text-white'
```
