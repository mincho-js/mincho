# 리터럴 CSS

Mincho.js는 TypeScript에서 자연스럽게 CSS를 작성하는 방법을 제공합니다. `css()` 함수는 직관적인 문법을 빌드 시점에 Vanilla Extract와 호환되는 스타일로 변환합니다.

## 개요 [#overview]

리터럴 CSS 계층은 Mincho.js 스타일링의 기반이며 다음 기능을 제공합니다.

- 완전한 자동 완성을 갖춘 타입 안전한 CSS
- 복잡한 설정 없이 사용하는 전처리기 수준의 기능
- 빌드 시점 추출을 통한 런타임 스타일 생성 비용 제거

```ts
import { css } from '@mincho-js/css'

const button = css({
  padding: 16,
  backgroundColor: 'blue',
  color: 'white',
  _hover: {
    backgroundColor: 'darkblue'
  }
})
```

## 단위 없는 속성 [#unitless-properties]

단위가 필요한 CSS 속성의 숫자는 자동으로 `px`로 변환됩니다. `opacity`, `flexGrow`, `zIndex`처럼 원래 단위가 없는 속성은 숫자로 유지됩니다.

```ts
css({
  // Converted to pixels
  padding: 10,        // → padding: 10px
  marginTop: 25,      // → margin-top: 25px
  borderRadius: 8,    // → border-radius: 8px

  // Remain unitless
  flexGrow: 1,        // → flex-grow: 1
  opacity: 0.5,       // → opacity: 0.5
  zIndex: 100,        // → z-index: 100
  lineHeight: 1.5     // → line-height: 1.5
})
```

## 벤더 접두사 [#vendor-prefixes]

벤더 접두사는 벤더 이름의 첫 글자를 대문자로 한 camelCase로 작성할 수 있습니다.

```ts
css({
  WebkitTapHighlightColor: 'rgba(0, 0, 0, 0)',
  MozAppearance: 'none',
  msOverflowStyle: 'none'
})
```

```css
/* Generated CSS */
-webkit-tap-highlight-color: rgba(0, 0, 0, 0);
-moz-appearance: none;
-ms-overflow-style: none;
```

## 대체 스타일 [#fallback-styles]

배열로 CSS 속성의 대체값을 제공합니다. 앞의 값은 뒤의 값을 지원하지 않는 브라우저에서 대체값으로 사용됩니다.

```ts
css({
  overflow: ['auto', 'overlay'],
  display: ['block', 'flex', 'grid']
})
```

```css
/* Generated CSS */
overflow: auto;
overflow: overlay;

display: block;
display: flex;
display: grid;
```

## 값 병합 [#merge-values]

[Less의 병합 기능](https://lesscss.org/features/#merge-feature)에서 영감을 받아 Mincho.js는 배열로 긴 값을 조합할 수 있습니다.

### 쉼표로 병합 (`$` 접미사) [#comma-merge--suffix]

`$` 접미사를 사용하면 배열 값을 쉼표로 연결합니다.

```ts
css({
  boxShadow$: ['inset 0 0 10px #555', '0 0 20px black'],
  fontFamily$: ['Pretendard', 'sans-serif']
})
```

```css
/* Generated CSS */
box-shadow: inset 0 0 10px #555, 0 0 20px black;
font-family: Pretendard, sans-serif;
```

### 공백으로 병합 (`_` 접미사) [#space-merge-_-suffix]

`_` 접미사를 사용하면 배열 값을 공백으로 연결합니다.

```ts
css({
  transform_: ['scale(2)', 'rotate(15deg)'],
  backgroundPosition_: ['center', 'top']
})
```

```css
/* Generated CSS */
transform: scale(2) rotate(15deg);
background-position: center top;
```

### 대체 스타일과 함께 사용 [#with-fallback-styles]

중첩 배열로 값 병합과 대체 스타일을 함께 사용합니다.

```ts
css({
  transform_: [
    'scale(2)',
    // Fallback: first for modern browsers, second for older
    ['rotate(0.5rad)', 'rotate(28.64deg)']
  ]
})
```

```css
/* Generated CSS */
transform: scale(2) rotate(0.5rad);
transform: scale(2) rotate(28.64deg);
```

## 간편한 important 지정 [#simply-important]

[Tailwind의 important 수정자](https://tailwindcss.com/docs/configuration#important-modifier)에서 영감을 받아 값 끝에 `!`를 붙이면 `!important`가 적용됩니다.

```ts
css({
  color: 'red!',
  display: 'flex !'  // Space before ! also works
})
```

```css
/* Generated CSS */
color: red !important;
display: flex !important;
```

대체 스타일에도 사용할 수 있습니다.

```ts
css({
  overflow: ['auto !', 'overlay']
})
```

## CSS 변수 [#css-variables]

[Sass 변수](https://sass-lang.com/documentation/variables/)에서 영감을 받아 `$` 접두사로 CSS 사용자 정의 속성을 정의하고 참조합니다.

### 변수 정의 [#defining-variables]

변수는 camelCase에서 `--` 접두사를 가진 kebab-case로 자동 변환됩니다.

```ts
css({
  $primaryColor: 'blue',
  $spacing: '16px',
  '--my-css-variable': 'green'  // Pure CSS syntax also works
})
```

```css
/* Generated CSS */
--primary-color: blue;
--spacing: 16px;
--my-css-variable: green;
```

### 변수 참조 [#referencing-variables]

```ts
css({
  $primaryColor: 'blue',
  color: '$primaryColor',
  padding: '$spacing'
})
```

```css
/* Generated CSS */
--primary-color: blue;
color: var(--primary-color);
padding: var(--spacing);
```

### 대체값 사용 [#with-fallback-values]

괄호로 대체값을 지정합니다.

```ts
css({
  color: '$primaryColor(red)',
  background: '$theme(white)'
})
```

```css
/* Generated CSS */
color: var(--primary-color, red);
background: var(--theme, white);
```

### 중첩 대체값 [#nested-fallbacks]

```ts
css({
  color: '$color1($color2($color3(black)))'
})
```

```css
/* Generated CSS */
color: var(--color1, var(--color2, var(--color3, black)));
```

### 다른 값 내부에서 사용 [#inside-other-values]

변수는 calc()를 비롯한 CSS 함수 안에서도 동작합니다.

```ts
css({
  $baseSize: '16px',
  width: 'calc($baseSize * 2)',
  height: 'calc($baseSize + 10px)'
})
```

```css
/* Generated CSS */
--base-size: 16px;
width: calc(var(--base-size) * 2);
height: calc(var(--base-size) + 10px);
```

### vars 속성 사용 [#using-vars-property]

Vanilla Extract의 `vars` 속성도 지원합니다.

```ts
css({
  vars: {
    $myCssVariable: 'blue',
    '--my-css-variable': 'green'
  }
})
```

## 간편한 의사 선택자 [#simple-pseudo-selectors]

[Panda CSS 조건](https://panda-css.com/)에서 영감을 받아 의사 클래스에는 `_` 접두사를, 의사 요소에는 `__` 접두사를 사용합니다.

### 의사 클래스 (`_` 접두사) [#pseudo-classes-_-prefix]

```ts
css({
  color: 'black',
  _hover: {
    color: 'blue'
  },
  _focus: {
    outline: '2px solid blue'
  },
  _firstOfType: {
    fontWeight: 'bold'
  },
  _disabled: {
    opacity: 0.5
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  color: 'black',
  selectors: {
    '&:hover': { color: 'blue' },
    '&:focus': { outline: '2px solid blue' },
    '&:first-of-type': { fontWeight: 'bold' },
    '&:disabled': { opacity: 0.5 }
  }
}
```

### 의사 요소 (`__` 접두사) [#pseudo-elements-__-prefix]

```ts
css({
  __before: {
    content: '""',
    display: 'block'
  },
  __after: {
    content: '""',
    clear: 'both'
  },
  __MozSelection: {
    background: 'blue'
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  selectors: {
    '&::before': { content: '""', display: 'block' },
    '&::after': { content: '""', clear: 'both' },
    '&::-moz-selection': { background: 'blue' }
  }
}
```

### camelCase 변환 [#camelcase-conversion]

camelCase 의사 선택자는 kebab-case로 자동 변환됩니다.

```ts
css({
  _firstOfType: { },   // → &:first-of-type
  _lastChild: { },     // → &:last-child
  __firstLetter: { },  // → &::first-letter
  __firstLine: { }     // → &::first-line
})
```

## 간편한 최상위 선택자 [#simply-toplevel-selectors]

의사 선택자와 속성 선택자는 `&` 없이 최상위에서 직접 사용할 수 있습니다.

```ts
css({
  ':hover:active': {
    color: 'red'
  },
  '[disabled]': {
    color: 'green'
  },
  '[href^="https://"][href$=".org"]': {
    color: 'blue'
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  selectors: {
    '&:hover:active': { color: 'red' },
    '&[disabled]': { color: 'green' },
    '&[href^="https://"][href$=".org"]': { color: 'blue' }
  }
}
```

## 복잡한 선택자 [#complex-selectors]

더 복잡한 선택자에는 최상위에서 `&` 자리 표시자를 직접 사용합니다.

```ts
css({
  '&:hover:not(:active)': {
    border: '2px solid aquamarine'
  },
  'nav li > &': {
    textDecoration: 'underline'
  },
  '&[data-active="true"]': {
    backgroundColor: 'blue'
  }
})
```

### 하위 호환성 [#backward-compatibility]

Vanilla Extract의 `selectors` 속성을 계속 지원합니다.

```ts
css({
  selectors: {
    '&:hover:not(:active)': {
      border: '2px solid aquamarine'
    },
    'a:nth-of-type(2) &': {
      opacity: 1
    }
  }
})
```

## 중첩 선택자 [#nested-selectors]

선택자는 여러 단계로 중첩할 수 있습니다. 각 단계에서 `&` 자리 표시자를 올바르게 해석합니다.

```ts
css({
  'nav li > &': {
    color: 'red',
    _hover: {
      color: 'green'
    },
    '&:hover:not(:active)': {
      color: 'blue'
    },
    ':root[dir=rtl] &': {
      color: 'black'
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  selectors: {
    'nav li > &': { color: 'red' },
    'nav li > &:hover': { color: 'green' },
    'nav li > &:hover:not(:active)': { color: 'blue' },
    ':root[dir=rtl] nav li > &': { color: 'black' }
  }
}
```

### 깊은 중첩 [#deep-nesting]

```ts
css({
  _hover: {
    _active: {
      color: 'red',
      '& li': {
        color: 'green'
      },
      'li > &': {
        color: 'blue'
      }
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  selectors: {
    '&:hover:active': { color: 'red' },
    '&:hover:active li': { color: 'green' },
    'li > &:hover:active': { color: 'blue' }
  }
}
```

### 쉼표로 구분한 선택자 [#with-comma-separated-selectors]

```ts
css({
  'nav li > &, .myClass li > &': {
    color: 'red',
    _hover: {
      color: 'green'
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  selectors: {
    'nav li > &, .myClass li > &': { color: 'red' },
    'nav li > &:hover, .myClass li > &:hover': { color: 'green' }
  }
}
```

## 속성 참조 [#property-reference]

[Stylus의 속성 조회](https://stylus-lang.com/docs/variables.html#property-lookup)에서 영감을 받아 `@`로 같은 규칙 안의 다른 속성 값을 참조합니다.

```ts
css({
  width: '50px',
  height: '@width',
  margin: 'calc(@width / 2)',
  paddingInline: 'calc(@width + @height)',
  paddingBlock: '@margin'
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  width: '50px',
  height: '50px',
  margin: 'calc(50px / 2)',
  paddingInline: 'calc(50px + 50px)',
  paddingBlock: 'calc(50px / 2)'
}
```

### 값 병합과 함께 사용 [#with-merge-values]

```ts
css({
  padding: '10px',
  background: 'black',
  boxShadow$: ['inset 0 0 @padding #555', '0 0 20px @background']
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  padding: '10px',
  background: 'black',
  boxShadow: 'inset 0 0 10px #555, 0 0 20px black'
}
```

### 중첩 컨텍스트에서 사용 [#in-nested-context]

속성 참조는 중첩 선택자 안에서도 동작하며 현재 범위의 값을 참조합니다.

```ts
css({
  padding: '10px',
  _hover: {
    margin: '@padding',
    padding: '20px'
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  padding: '10px',
  selectors: {
    '&:hover': {
      margin: '20px',  // References the overridden padding
      padding: '20px'
    }
  }
}
```

## 중첩 속성 [#nested-properties]

대문자로 시작하는 키로 관련 CSS 속성을 묶습니다.

```ts
css({
  padding: {
    BlockEnd: 3,
    Right: '20px'
  },
  background: {
    Color: 'red',
    Image: 'none'
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  paddingBlockEnd: 3,
  paddingRight: '20px',
  backgroundColor: 'red',
  backgroundImage: 'none'
}
```

### 대체 스타일과 함께 사용 [#with-fallback-styles-1]

```ts
css({
  background: {
    Color: [
      '#b32323',
      'color(display-p3 .643308 .192455 .167712)',
      'lab(40% 56.6 39)'
    ]
  }
})
```

### 중첩 속성에서 속성 참조 [#property-reference-in-nested-properties]

```ts
css({
  '@media': {
    'screen and (min-width: 768px)': {
      margin: 10,
      _hover: {
        padding: {
          BlockEnd: 3,
          Right: '20px',
          Left: '@margin',
          InlineStart: ['@Left', '@Right']
        }
      }
    }
  }
})
```

## 속성 조건 [#property-conditions]

`base` 키워드로 기본값을 설정하고 상태별 조건을 지정합니다.

```ts
css({
  background: {
    base: 'red',
    _hover: 'green',
    '[disabled]': 'blue',
    'nav li > &': 'black',
    '@media (prefers-color-scheme: dark)': 'white',
    '@media': {
      'screen and (min-width: 768px)': 'grey'
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  background: 'red',
  selectors: {
    '&:hover': { background: 'green' },
    '&[disabled]': { background: 'blue' },
    'nav li > &': { background: 'black' }
  },
  '@media': {
    '(prefers-color-scheme: dark)': { background: 'white' },
    'screen and (min-width: 768px)': { background: 'grey' }
  }
}
```

### 중첩 속성과 함께 사용 [#with-nested-properties]

```ts
css({
  background: {
    Color: {
      base: 'transparent',
      _hover: 'Highlight',
      _active: '@_hover',  // Reference another condition
      '@media (prefers-reduced-motion)': 'MenuText'
    }
  }
})
```

### 복합 예제 [#complex-example]

```ts
css({
  background: {
    _hover: {
      base: [
        '#706a43',
        'color-mix(in hsl, hsl(120deg 10% 20%) 25%, hsl(30deg 30% 40%))'
      ],
      Color: [
        '#b32323',
        'color(display-p3 .643308 .192455 .167712)'
      ]
    },
    'nav > &': {
      Color: {
        base: ['#6a805d', 'color(a98-rgb .44091 .49971 .37408)'],
        __after: ['#00c4ff', 'hwb(194 0% 0%)']
      }
    }
  }
})
```

## At 규칙 [#at-rules]

### 최상위 At 규칙 [#top-level-at-rules]

At 규칙을 최상위에 직접 작성합니다.

```ts
css({
  '@media print': {
    padding: 5
  },
  '@supports (display: grid)': {
    display: 'grid'
  }
})
```

### 중첩 At 규칙 [#nested-at-rules]

같은 At 규칙 아래에 여러 조건을 묶습니다.

```ts
css({
  '@media': {
    'screen and (min-width: 768px)': {
      padding: 10
    },
    '(prefers-reduced-motion)': {
      transitionProperty: 'color'
    }
  }
})
```

### 깊은 중첩 [#deep-nesting-1]

At 규칙은 서로 중첩할 수 있습니다. 조건은 `and`로 병합됩니다.

```ts
css({
  '@media (prefers-color-scheme: dark)': {
    color: 'red',
    '@media (min-width: 768px)': {
      color: 'green',
      '@media': {
        print: 'blue'
      }
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  '@media': {
    '(prefers-color-scheme: dark)': { color: 'red' },
    '(prefers-color-scheme: dark) and (min-width: 768px)': { color: 'green' },
    '(prefers-color-scheme: dark) and (min-width: 768px) and print': { color: 'blue' }
  }
}
```

### 레이어 중첩 [#layer-nesting]

`@layer` 조건은 `and` 대신 `.`으로 병합됩니다.

```ts
css({
  '@layer framework': {
    '@layer': {
      layout: {
        color: 'black'
      },
      utilities: {
        color: 'white'
      }
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  '@layer': {
    'framework.layout': { color: 'black' },
    'framework.utilities': { color: 'white' }
  }
}
```

## At 규칙과 중첩 선택자 [#nested-selectors-with-at-rules]

선택자와 At 규칙은 순서에 관계없이 조합할 수 있습니다.

```ts
css({
  '@media (prefers-color-scheme: dark)': {
    'nav li > &': {
      _hover: {
        background: 'red'
      }
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  '@media': {
    '(prefers-color-scheme: dark)': {
      selectors: {
        'nav li > &:hover': { background: 'red' }
      }
    }
  }
}
```

### 선택자 안에 At 규칙 사용 [#selectors-first-then-at-rules]

```ts
css({
  'nav li > &': {
    background: 'red',
    '@media (prefers-color-scheme: dark)': {
      background: 'blue',
      _hover: {
        background: 'white'
      }
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  selectors: {
    'nav li > &': { background: 'red' }
  },
  '@media': {
    '(prefers-color-scheme: dark)': {
      selectors: {
        'nav li > &': { background: 'blue' },
        'nav li > &:hover': { background: 'white' }
      }
    }
  }
}
```

### 선택자와 여러 At 규칙 [#multiple-at-rules-with-selectors]

```ts
css({
  '@media (prefers-color-scheme: dark)': {
    '@media (min-width: 768px)': {
      '@supports (display: grid)': {
        color: 'black'
      }
    }
  }
})
```

다음 CSS가 생성됩니다.

```ts
// Vanilla Extract output
{
  '@supports': {
    '(display: grid)': {
      '@media': {
        '(prefers-color-scheme: dark) and (min-width: 768px)': {
          color: 'black'
        }
      }
    }
  }
}
```

## 익명 At 규칙 [#anonymous-at-rules]

### 인라인 키프레임 [#inline-keyframes]

`animationName` 안에 키프레임을 인라인으로 정의합니다.

```ts
css({
  animationName: {
    from: { opacity: 0 },
    '50%': { opacity: 0.3 },
    to: { opacity: 1 }
  },
  animationDuration: '1s'
})
```

### 인라인 글꼴 정의 [#inline-font-face]

`fontFamily` 안에 글꼴을 인라인으로 정의합니다.

```ts
css({
  fontFamily: {
    fontWeight: 900,
    src$: [
      "local('Pretendard Regular')",
      "url(./fonts/Pretendard-Regular.woff2) format('woff2')",
      "url(./fonts/Pretendard-Regular.woff) format('woff')"
    ]
  }
})
```

### 여러 글꼴 정의 [#multiple-font-faces]

```ts
css({
  fontFamily$: [
    {
      fontFamily: 'CustomFont',
      fontWeight: 400,
      src: "url('/fonts/custom-regular.woff2')"
    },
    {
      fontFamily: 'CustomFont',
      fontWeight: 700,
      src: "url('/fonts/custom-bold.woff2')"
    }
  ]
})
```

## CSS 조합 [#css-composition]

배열로 여러 스타일을 결합합니다.

```ts
const base = css({ padding: 12 })

const primary = css([
  base,
  { background: 'blue', color: 'white' }
])

const secondary = css([
  base,
  { background: 'gray', color: 'black' }
])
```

```ts
css([
  'existingClassName',
  () => 'dynamicClassName',
  (size = 10) => ({ padding: size, margin: size })
])
```

전역 스타일에는 `globalCss()`를 사용합니다.

```ts
import { globalCss } from '@mincho-js/css'

globalCss({
  '*': {
    boxSizing: 'border-box',
    margin: 0,
    padding: 0
  },

    fontFamily: 'system-ui, sans-serif',

  },
  'a': {
    color: '$primaryColor',
    _hover: {
      textDecoration: 'underline'
    }
  }
})
```

## 변형 참조 [#variant-reference]

`rules()` 함수의 고급 사용 사례에서는 `%`로 변형을 참조할 수 있습니다.

```ts
css({
  '&:hover:not(:active) %someVariant': {
    border: '2px solid red'
  }
})
```

주로 `rules()` 함수 내부에서 사용합니다. 자세한 내용은 [스타일 규칙](/ko/docs/rules)을 참조하세요.

## CSS 메서드 [#css-methods]

`css` 함수는 자주 사용하는 패턴을 위한 추가 메서드를 제공합니다.

### css.raw() [#cssraw]

클래스 이름을 생성하지 않고 스타일 객체를 그대로 반환합니다. 스타일 병합이나 디버깅에 유용합니다.

```ts
const baseStyles = css.raw({
  color: 'blue',
  backgroundColor: '#EEEEEE'
})

// Use in composition
const button = css([baseStyles, { padding: 16 }])
```

### css.multiple() [#cssmultiple]

스타일 맵에서 여러 클래스 이름을 만듭니다. Vanilla Extract의 `styleVariants`와 비슷합니다.

```ts
const backgrounds = css.multiple({
  primary: { background: 'blue' },
  secondary: { background: 'aqua' },
  danger: { background: 'red' }
})

// backgrounds.primary: className
// backgrounds.secondary: className
// backgrounds.danger: className
```

### css.with() [#csswith]

스타일/객체 모드 또는 위치 인수 믹스인 모드로 사용 범위가 제한된 CSS 함수를 만듭니다. 콜백이 없거나 콜백 매개변수가 하나이면 `CSSRuleWith<T>` 스타일 객체를 사용합니다. 매개변수가 두 개 이상인 콜백은 위치 인수 믹스인 모드를 사용합니다.

#### 타입 제한 [#type-restrictions]

허용되는 속성과 값을 제한합니다.

```ts
const myCss = css.with<{
  color: true;              // Required, any value
  background: 'blue' | 'grey';  // Required, specific values only
  padding?: true;           // Optional, any value
  position: false;          // Forbidden
}>()

myCss({
  color: 'red',
  background: 'blue'
})
```

#### 객체 매개변수 믹스인 패턴 [#object-parameter-mixin-pattern]

콜백이 `CSSRuleWith<T>` 스타일 객체를 변환한다면 객체 매개변수 하나를 사용합니다. 이 경우 스타일/객체 모드를 유지하므로 직접 호출과 `.multiple()`에 객체 값을 전달합니다.

```ts
const objectBoxMixin = css.with<{ size: number; radius?: number }>(
  ({ size, radius = 0 }) => ({
    width: size,
    height: size,
    borderRadius: radius
  })
)

const smallBox = objectBoxMixin({ size: 50 })
const roundedBox = objectBoxMixin({ size: 100, radius: 8 })
const objectBoxVariants = objectBoxMixin.multiple({
  small: { size: 50 },
  rounded: { size: 100, radius: 8 }
})
```

#### 위치 인수 믹스인 패턴 [#positional-mixin-pattern]

호출 인수를 콜백의 인수와 맞추려면 콜백 매개변수를 두 개 이상 사용합니다. 직접 호출과 `.raw()`는 위치 인수를 받습니다. 이 모드에서 `.multiple()`은 튜플 값을 사용합니다.

```ts
const boxMixin = css.with((size: number, radius?: number) => ({
  width: size,
  height: size,
  borderRadius: radius ?? 0
}))

const smallBox = boxMixin(50)
const roundedBox = boxMixin(100, 8)
const rawBox = boxMixin.raw(100, 8)
const boxVariants = boxMixin.multiple({
  small: [50],
  rounded: [100, 8]
} as const)
```

콜백 인수가 하나이면 `CSSRuleWith<T>` 스타일 변환 모드를 유지하므로 위치 인수 하나는 지원하지 않습니다. 단일 값 믹스인에는 객체 매개변수를 사용하세요. 스타일/객체 모드의 `.multiple()`은 객체 값을, 위치 인수 믹스인 모드의 `.multiple()`은 튜플 값을 사용합니다.

## 하위 호환성 [#backward-compatibility-1]

Mincho.js는 Vanilla Extract 문법과의 완전한 하위 호환성을 유지합니다.

```ts
css({
  // Vanilla Extract style vars
  vars: {
    '--custom-color': 'blue'
  },

  // Both syntaxes work
  color: 'var(--custom-color)',
  backgroundColor: '$customColor',

  // Both selector syntaxes work
  ':hover': { color: 'red' },
  _hover: { color: 'red' },

  // selectors property still works
  selectors: {
    '&:hover:not(:active)': { }
  }
})
```
