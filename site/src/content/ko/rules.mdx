# 스타일 규칙

`rules()` 함수는 변형과 props를 통해 동적 스타일링 기능을 제공합니다. [Stitches 변형](https://stitches.dev/docs/variants)의 패턴 매칭 기능과 Vanilla Extract의 정적 추출을 결합합니다.

## 개요 [#overview]

`css()`가 정적 스타일을 만드는 반면, `rules()`는 전달된 옵션에 따라 서로 다른 클래스 이름을 반환하는 함수를 만듭니다.

```ts
import { rules } from '@mincho-js/css'

const button = rules({
  padding: 12,
  backgroundColor: 'blue',
  color: 'white',

  variants: {
    size: {
      small: { padding: 8 },
      large: { padding: 16 }
    }
  }
})

// Usage
button()                    // base styles
button({ size: 'small' })   // base + small variant
button({ size: 'large' })   // base + large variant
```

## 기본 사용법 [#basic-usage]

`css()`와 마찬가지로 객체를 사용해 스타일을 정의합니다. `rules()` 함수는 클래스 이름을 생성하는 호출 가능한 함수를 반환합니다.

```ts
const myRule = rules({
  color: 'blue',
  backgroundColor: 'white',
  borderRadius: 6
})
```

```css
/* Generated CSS */
.[FILE_NAME]_myRule__[HASH] {
  color: blue;
  background-color: white;
  border-radius: 6px;
}
```

컴포넌트에서 다음과 같이 사용합니다.

```tsx
function MyComponent() {
  return <div className={myRule()}>Content</div>
}
```

### base 필드 [#base-field]

Vanilla Extract 레시피와의 호환성을 위해 `base` 필드를 사용할 수 있습니다.

```ts
const myRule = rules({
  base: {
    color: 'blue',
    backgroundColor: 'white'
  }
})
```

최상위 스타일과 `base`를 함께 사용하면 `base`가 우선합니다.

```ts
const myRule = rules({
  color: 'red',        // overridden
  base: {
    color: 'blue'      // this wins
  }
})
```

## 규칙 확장 [#extending-rules]

`rules.extends(parent, options, debugId?)`로 기존 규칙을 상속합니다.

```ts
const button = rules({
  color: 'white',
  variants: {
    size: {
      small: { padding: 8 },
      large: { padding: 16 }
    }
  },
  props: ['width'],
  defaultVariants: { size: 'small' }
})

const accentButton = rules.extends(button, {
  backgroundColor: 'purple',
  variants: {
    size: {
      large: { padding: 24 },
      huge: { padding: 32 }
    }
  },
  defaultVariants: { size: 'large' }
}, 'accentButton')

accentButton({ size: 'small' })
accentButton({ size: 'huge' })
accentButton.props({ width: 200 })
```

자식은 상속된 기본, 변형, 복합 클래스와 자신이 추가한 스타일의 클래스를 함께 포함합니다. 기존 스타일은 재사용되고 부모는 변경되지 않습니다. CSS 우선순위가 같을 때는 모듈 의존 관계를 통해 부모 CSS가 먼저 불러와지므로 자식 선언이 우선합니다. 자식의 기본 스타일과 부모의 변형이 겹치는 경우에도 동일하게 적용됩니다.

- 변형 그룹을 상속하며 새로운 값을 추가할 수 있습니다.
- 기본값은 변형 이름별로 병합합니다. 두 규칙의 복합 조건이 모두 적용되며, 자식의 복합 콜백은 상속된 변형과 새 변형을 참조할 수 있습니다.
- 상속된 props는 CSS 변수를 유지합니다. prop을 재정의하면 자식의 대상과 대체값에 대한 선언이 추가되고, 상속된 대상 선언은 유지됩니다.
- `classNames.base`와 `classNames.variants`는 자식이 스타일을 추가한 경우 자식의 단일 클래스를, 그렇지 않으면 부모의 클래스를 참조합니다. 규칙을 호출하면 필요한 모든 클래스를 포함합니다.
- 빈 확장은 부모의 클래스를 재사용합니다. 확장 결과는 다시 확장할 수 있습니다.

타입이 지정된 팩터리도 기존 콜백을 통해 확장할 수 있습니다.

```ts
const coloredRules = rules.with<{ color: string }>(
  ({ color }) => ({ color })
)
const coloredButton = coloredRules.extends(button, { color: 'navy' })
```

가져온 직렬화된 규칙은 생산자가 확장 메타데이터를 포함한 경우 확장할 수 있습니다. 이전 생산자의 결과를 확장하려면 먼저 다시 빌드하세요. 패키지 스타일은 빌드 통합이 부모 CSS 가져오기를 유지할 수 있도록 기존 `style.css` 내보내기를 제공해야 합니다. `.css.ts` 파일에서 vanilla-extract를 직접 사용할 때는 자식 스타일보다 먼저 부모 패키지의 `style.css`를 명시적으로 가져오세요.

## 변형 [#variants]

런타임에 선택할 수 있는 여러 스타일 변형을 정의합니다. 각 변형 그룹은 이름이 있는 옵션을 포함합니다.

```ts
const button = rules({
  padding: 12,
  borderRadius: 6,

  variants: {
    color: {
      brand: {
        color: '#FFFFA0',
        backgroundColor: 'blueviolet'
      },
      accent: {
        color: '#FFE4B5',
        backgroundColor: 'slateblue'
      }
    },
    size: {
      small: { padding: 8, fontSize: 12 },
      medium: { padding: 12, fontSize: 14 },
      large: { padding: 16, fontSize: 16 }
    }
  }
})
```

```css
/* Generated CSS */
.[FILE_NAME]_button__[HASH] {
  padding: 12px;
  border-radius: 6px;
}

.[FILE_NAME]_button_color_brand__[HASH] {
  color: #FFFFA0;
  background-color: blueviolet;
}
.[FILE_NAME]_button_color_accent__[HASH] {
  color: #FFE4B5;
  background-color: slateblue;
}

.[FILE_NAME]_button_size_small__[HASH] { ... }
.[FILE_NAME]_button_size_medium__[HASH] { ... }
.[FILE_NAME]_button_size_large__[HASH] { ... }
```

객체를 전달해 변형을 선택합니다.

```ts
button({ color: 'brand', size: 'large' })
```

### 불리언 변형 [#boolean-variants]

불리언 형태의 변형에는 `true`와 `false`를 키로 사용합니다.

```ts
const button = rules({
  variants: {
    outlined: {
      true: { border: '1px solid black' },
      false: { border: '1px solid transparent' }
    }
  }
})

button({ outlined: true })
button({ outlined: false })
```

## 불리언 선택 [#boolean-selections]

불리언 상태도 일반적인 변형 그룹입니다. 활성 상태에만 적용할 스타일은 `true` 분기에 정의하고, 비활성 상태에 별도 스타일이 있으면 `false`를 추가합니다. 분기가 없으면 클래스가 추가되지 않습니다.

```ts
const button = rules({
  variants: {
    rounded: { true: { borderRadius: 999 } },
    disabled: {
      true: { opacity: 0.5, pointerEvents: 'none' },
      false: { opacity: 1 }
    },
    size: { large: { padding: 16 } }
  }
})

button({ rounded: true, disabled: false })
button(['rounded', { size: 'large' }])
```

`'rounded'`와 같은 배열 항목은 해당 불리언 변형의 `true` 분기를 선택합니다. 객체 문법으로는 `false`도 명시적으로 지정할 수 있습니다.

기존 `toggles` 정의를 이전하려면 각 스타일을 `variants` 아래의 `true` 분기로 옮깁니다. 클래스 순서를 유지하도록 이전한 불리언 그룹은 기존 변형 그룹 뒤에 배치합니다. 기본 선택과 복합 조건의 의미는 유지됩니다. 명시적 `PatternOptions` 타입은 이제 `<Variants, Props>`를 받으며 별도의 토글 타입 매개변수나 `ConditionalVariants` 병합 타입은 없습니다.

## 기본 변형 [#default-variants]

`defaultVariants`로 변형의 기본값을 설정합니다.

```ts
const button = rules({
  variants: {
    color: {
      brand: { backgroundColor: 'blueviolet' },
      accent: { backgroundColor: 'slateblue' }
    },
    size: {
      small: { padding: 8 },
      medium: { padding: 12 },
      large: { padding: 16 }
    }
  },
  defaultVariants: {
    color: 'brand',
    size: 'medium'
  }
})

button()  // Applies brand color and medium size
button({ size: 'large' })  // Applies brand color (default) and large size
```

불리언 변형에도 기본값을 지정할 수 있습니다.

```ts
const button = rules({
  variants: {
    rounded: { true: { borderRadius: 999 } },
    disabled: { true: { opacity: 0.5 } }
  },
  defaultVariants: { rounded: true }
})
```

## 복합 변형 [#compound-variants]

특정 변형 조합이 일치할 때 추가 스타일을 적용합니다.

```ts
const button = rules({
  variants: {
    color: {
      brand: { color: '#FFFFA0' },
      accent: { color: '#FFE4B5' }
    },
    size: {
      small: { padding: 8 },
      medium: { padding: 12 },
      large: { padding: 16 }
    },
    outlined: {
      true: { border: '1px solid' },
      false: { border: 'none' }
    }
  },

  compoundVariants: ({ color, size, outlined }) => [
    {
      condition: [color.brand, size.small],
      style: { fontSize: 14 }
    },
    {
      condition: [outlined.true, color.accent],
      style: { borderColor: 'slateblue' }
    }
  ]
})
```

`compoundVariants` 함수는 변형 조건 객체를 받아 복합 규칙 배열을 반환합니다. 각 규칙은 다음을 지정합니다.
- `condition`: 일치해야 하는 변형 조건 배열
- `style`: 모든 조건이 일치할 때 적용할 추가 스타일

```ts
// This will apply the compound style for [color.brand, size.small]
button({ color: 'brand', size: 'small' })
```

## Props [#props]

Props는 CSS 변수를 사용해 동적인 값을 지원합니다. 미리 정의하는 변형과 달리 props는 런타임에 어떤 값이든 받을 수 있습니다.

### 단순한 Props [#simple-props]

속성 이름 배열로 CSS 변수 바인딩을 만듭니다.

```ts
const box = rules({
  props: ['color', 'backgroundColor']
})
```

```css
/* Generated CSS */
.[FILE_NAME]_box__[HASH] {
  color: var(--[FILE_NAME]_box_color__[HASH]);
  background-color: var(--[FILE_NAME]_box_backgroundColor__[HASH]);
}
```

`result.props()`로 인라인 스타일 변수를 생성합니다.

```tsx
import { box } from './styles.css'

function Box({ textColor, bgColor }) {
  return (
    <div
      className={box()}
      style={box.props({ color: textColor, backgroundColor: bgColor })}
    >
      Content
    </div>
  )
}
```

### 대상이 있는 Props [#props-with-targets]

하나의 prop을 여러 CSS 속성에 매핑합니다.

```ts
const box = rules({
  props: {
    size: { targets: ['padding', 'margin'] },
    radius: { targets: ['borderRadius'] }
  }
})
```

```css
/* Generated CSS */
.[FILE_NAME]_box__[HASH] {
  padding: var(--[FILE_NAME]_box_size__[HASH]);
  margin: var(--[FILE_NAME]_box_size__[HASH]);
  border-radius: var(--[FILE_NAME]_box_radius__[HASH]);
}
```

### 기본값이 있는 Props [#props-with-default-values]

`base`로 대체값을 설정합니다.

```ts
const box = rules({
  props: {
    size: { base: '1rem', targets: ['padding', 'margin'] },
    radius: { base: 0, targets: ['borderRadius'] }
  }
})
```

```css
/* Generated CSS */
.[FILE_NAME]_box__[HASH] {
  padding: var(--[FILE_NAME]_box_size__[HASH], 1rem);
  margin: var(--[FILE_NAME]_box_size__[HASH], 1rem);
  border-radius: var(--[FILE_NAME]_box_radius__[HASH], 0);
}
```

### 혼합 Props [#mixed-props]

단순한 prop 정의와 복잡한 prop 정의를 함께 사용합니다.

```ts
const box = rules({
  props: [
    'color',
    'backgroundColor',
    {
      size: { base: '1rem', targets: ['padding', 'margin'] }
    }
  ]
})
```

## 여러 규칙 [#multiple-rules]

`rules.multiple()`로 관련된 여러 규칙을 한 번에 만듭니다.

```ts
const components = rules.multiple({
  button: {
    padding: 12,
    variants: {
      variant: {
        primary: { backgroundColor: 'blue' },
        secondary: { backgroundColor: 'gray' }
      }
    }
  },
  input: {
    padding: 8,
    variants: {
      state: {
        error: { borderColor: 'red' },
        success: { borderColor: 'green' }
      }
    }
  }
})

// Usage
components.button({ variant: 'primary' })
components.input({ state: 'error' })
```

## 타입 제약 [#type-constraints]

`rules.with()`로 입력 타입이 제한된 규칙을 만듭니다.

```ts
const themeRule = rules.with<{ bg: string; text: string }>(
  ({ bg, text }) => ({
    backgroundColor: bg,
    color: text,
    variants: {
      emphasis: {
        subtle: { opacity: 0.7 },
        strong: { fontWeight: 'bold' }
      }
    }
  })
)

// Create themed variants
const themes = themeRule.multiple({
  light: { bg: '#ffffff', text: '#000000' },
  dark: { bg: '#1a1a1a', text: '#ffffff' }
})

themes.light({ emphasis: 'strong' })
themes.dark({ emphasis: 'subtle' })
```

## 원본 규칙 [#raw-rules]

`rules.raw()`로 처리되지 않은 규칙 객체를 가져옵니다.

```ts
const buttonOptions = rules.raw({
  base: { padding: 12 },
  variants: {
    size: {
      small: { padding: 8 },
      large: { padding: 16 }
    }
  }
})

// Use later with rules()
const button = rules(buttonOptions)
```

## 메타데이터 접근 [#accessing-metadata]

반환된 함수에서 메타데이터에 접근할 수 있습니다.

```ts
const button = rules({
  variants: {
    color: { brand: {...}, accent: {...} },
    size: { small: {...}, large: {...} }
  }
})

// Get variant names
button.variants()  // ['color', 'size']

// Access class names directly
button.classNames.base           // base class name
button.classNames.variants.color.brand  // brand variant class name
```

## css()와 함께 사용 [#with-css]

규칙은 `css()`와 조합할 수 있습니다.

```ts
const baseStyle = css({ color: 'red' })

const myRule = rules({
  backgroundColor: 'blue',
  variants: {
    rounded: { true: { borderRadius: 999 } }
  }
})

// Compose in css()
const combined = css([baseStyle, myRule])  // Auto-evaluates myRule()
```

## 제약 사항 [#limitations]

규칙은 빌드 시점에 정적으로 추출되므로 일부 패턴은 지원하지 않습니다.

### 조건부 Props 미지원 [#no-conditional-props]

```ts
// This won't work
const box = rules((props) => ({
  display: 'flex',
  ...(props.vertical
    ? { flexDirection: 'column' }
    : { flexDirection: 'row' })
}))
```

대신 변형을 사용합니다.

```ts
const box = rules({
  display: 'flex',
  variants: {
    direction: {
      vertical: { flexDirection: 'column' },
      horizontal: { flexDirection: 'row' }
    }
  }
})
```

### 런타임에 생성하는 스타일 [#runtime-generated-styles]

런타임에 정해지는 값에는 props를 사용합니다.

```ts
// styles.css.ts
export const bubble = rules({
  props: ['x', 'y']
})

// Component.tsx
function Bubble() {
  const x = Math.random() * 100
  const y = Math.random() * 100

  return (
    <div
      className={bubble()}
      style={bubble.props({ x: `${x}%`, y: `${y}%` })}
    />
  )
}
```
