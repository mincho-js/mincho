Add the `selectors` namespace with position and quantity conditions, selector
composition, and filtered direct-child matching. Export the same 33 functions
from the CSS package and the lightweight `@mincho-js/css/selectors` entry, with
ESM tree shaking, CommonJS interoperability, and TypeScript declarations for
Node10 and NodeNext resolution. Helpers evaluated in `.css.ts` leave standard
CSS without selector utility JavaScript in application bundles.
