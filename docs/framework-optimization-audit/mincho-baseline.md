# Mincho 비교 기준

> 보관된 조사 기록입니다. Mincho 비교 기준은 2026-09-23의 전체 개발 스택
> `33911861`이며, 이 문서가 추가되는 PR이나 현재 `main`의 지원 기능 목록이
> 아닙니다. 외부 소스 링크는 조사 당시 커밋으로 고정했습니다.
> 이 PR에 없는 Mincho 소스는 당시 저장소 상대 경로와 라인을 코드로 표시합니다.

조사 기준: `33911861786b4ee634f637e5635a1049dfaea6e3` (2026-09-23).

## 아직 구분해서 봐야 할 경계

- 일반 `css()`는 scoped rule이다. `defineRules`의 원자화와 preset dedupe를
  전체 CSS의 전역 원자화·dedupe로 확대 해석하면 안 된다.
- source 의존 그래프와 unused export **변경 시 재사용**은 존재한다. 이것만으로
  CSS selector/recipe variant의 사용 여부를 분석해 제거한다고 할 수는 없다.
- `dist-chunk`는 output 단계 생성까지 구현됐다. 다만 같은 IR의 순수
  `generateVanillaCss()` 결과를 preview와 각 output 사이에서 memo하는 별도 계층은 없다.
- `defineRules.cx` 조건 table은 이미 구현됐지만 initializer 호출을 빌드타임
  문자열로 완전히 굳히는 기능과는 다르다.
- compile worker·runtime cache·CSS sharing은 비용이 있다. 기존 측정에서도
  모든 workload에 이득이 있지는 않았으므로, 기능 유무를 속도 순위로 해석하지 않는다.
